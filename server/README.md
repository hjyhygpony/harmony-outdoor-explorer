# 户外群组实时位置同步服务

## 快速开始

### 1. 安装依赖
```bash
cd server
npm install
```

### 2. 启动服务器
```bash
npm start
```

服务器将在 `ws://YOUR_IP:8080` 启动

### 3. 获取服务器IP

Windows:
```bash
ipconfig
```
找到 `IPv4 地址`，例如 `192.168.1.100`

Mac/Linux:
```bash
ifconfig
```

### 4. 在App中连接

1. 打开App，进入"实时群组"
2. 输入你的昵称
3. 输入服务器IP（如 `192.168.1.100`）
4. 点击"连接服务器"

### 5. 测试多设备

1. 在两个模拟器/设备上安装App
2. 都连接到同一个服务器
3. 一个设备创建群组，获得邀请码
4. 另一个设备用邀请码加入群组
5. 两个设备就能看到彼此的位置了！

## 功能说明

- **创建群组**: 生成6位邀请码
- **加入群组**: 输入邀请码加入
- **位置共享**: 每5秒自动上报位置
- **SOS求助**: 长按SOS按钮发送紧急求助
- **实时同步**: WebSocket实时推送位置更新

## 注意事项

- 确保手机/模拟器和服务器在同一局域网
- 模拟器可能需要配置网络桥接
- 如果连接失败，检查防火墙设置
